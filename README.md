# Luna: Cloud Love Runner — edição com cenário da arte

Esta versão usa a imagem enviada como cenário principal do jogo (`www/assets/cloud-love-world.png`).

## Jogar no navegador
Abra `www/index.html`.

## Android/iOS
É o mesmo projeto Capacitor da versão Deluxe. O workflow Android gera um APK debug no GitHub Actions; o workflow iOS gera um build para simulador.

## Controles
- PC: A/D ou setas esquerda/direita para andar; Espaço/Seta para cima para pular.
- Celular: botões na tela.

## Conteúdo
- Cenário romântico de nuvens baseado na imagem enviada.
- 3 fases.
- Plataformas com colisão.
- Corações colecionáveis.
- Inimigos.
- Portal final.
- Nome personalizado na proposta.
- Música procedural e efeitos sonoros.
- Tela final com pedido de namoro e conquista.
